## Project Name
Library Hub

## Purpose
This is the Online Book Borrow Platform. This Project helps the user to explore the new books, read books, search expected Book also user can Borrow a Book. This webpage is user friendly. This webpage is responsive for all device. 

## Live Site link
- https://eighth-assignment-ph-13.vercel.app

## Key Features
- Search Book Easily by Book Title
- Using FAQ section for better user experience
- Browse and Explore new arrive books
- Google Authentication Implement for secure
- Branch section Added
- User Friendly Interface
- Responsive for All Device
